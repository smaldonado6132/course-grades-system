# Course Grades System

Java application that manages and evaluates graded activities for a course.

The program stores multiple grading components, calculates average scores, determines letter grades, and identifies the highest and lowest scores using object-oriented programming concepts.

##Features
- Calculates numeric and letter grades
- Supports multiple graded activity types
- Finds highest and lowest scores
- Uses inheritance and arrays of objects

##Technologies
- Java
- NetBeans
- Object-Oriented Programming
